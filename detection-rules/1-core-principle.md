# Core Principle

## Keep Latter, Delete Former

The later version is usually more complete, so:
- Delete the earlier one (stutter/fragment)
- Keep the later one (complete sentence)

## Exceptions

When the user explicitly says "the later one sounds better", keep latter delete former.
When the user explicitly says "the earlier one sounds better", keep former delete latter.
